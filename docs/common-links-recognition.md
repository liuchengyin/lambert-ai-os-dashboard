# 常用链接识别优化

- 锁定只限制改名、删除和拖动，不限制添加。桌面和手机的搜索栏都保留添加入口，分组内也可直接添加。
- 粘贴地址后450毫秒自动识别；常见 DeepSeek、Google 页面先按精确域名和路径识别，其他网站通过同源后端读取 HTML 标题和网站声明图标。成功后名称只读，以识别结果保存。网站阻止抓取或网络不可用时才开放手动补充。
- URL变化取消旧请求，并校验版本，避免慢响应覆盖新网址；识别中不能保存，取消弹窗后不写回旧响应。保存失败保留草稿及原始链接数据。
- 旧链接的名称、备注、扩展字段保留。已知站点显示本地清晰图标，不再拉伸旧低分辨率 favicon。其他站点优先 SVG/高清图标，失败显示清晰文字标识，不显示破图。
- 链接识别不调用 AI，不产生 DeepSeek Token 费用。
- 后端只允许公开 HTTP(S)、标准端口，不带网站登录 Cookie；校验 DNS 并固定连接地址，每次跳转重新检查，拒绝私网、回环、链路本地和混合 DNS 结果。限制页面262144字节、3次跳转、6.5秒超时、并发4个；短期缓存最多100条。

## 图标来源

- DeepSeek：官方平台 HTML 声明的 `https://fe-static.deepseek.com/platform/favicon.svg`。
- Google：官方静态资源 `https://www.gstatic.com/images/branding/googleg/1x/googleg_standard_color_128dp.png`，本地保留128像素源图，以42像素显示。

图标仅用于识别书签指向的网站，不表示与网站运营方存在合作关系。

## 第二版：快速生成书签

参考 gogoing.work 的公开操作：搜索框粘贴网址后回车，生成带名称、图标、简介的候选卡片，选择分组保存。常用链接区改为浅灰底、分组面板和四列白色信息卡片，手机自动单列；保留工作台自己的导航、数据和其他模块。

前后端共用 `lib/link-sites.js` 的常见网站目录，按域名边界匹配。豆瓣电影桌面/手机版、豆瓣读书、哔哩哔哩桌面/手机版等首页无需依赖抓取。具体文章和视频链接优先读取页面信息；网站限制抓取时只识别所属平台，并明确提示未取得具体页面标题。短链接也保留原始地址，不能把平台名当成已获取的视频标题。其他未收录网站仍走安全元信息抓取。

简介自动填写，但保留用户已有备注和手动修改；取消候选卡不写入数据。网页读取到 head 结束或大小上限即可解析，避免大型网页的正文导致本来可用的标题识别失败。

新本地图标来源：豆瓣使用 Simple Icons 开源仓库的豆瓣矢量标识 `https://github.com/simple-icons/simple-icons/blob/develop/icons/douban.svg`（CC0），应用豆瓣绿色；哔哩哔哩官网声明的 `https://i0.hdslb.com/bfs/static/jinkela/long/images/512.png`。

`Common Links Flash Review` 只在专用审查分支收到指定的一次性提交消息时运行，先执行链接元信息测试与实际识别样例，再将结果及指定源码交给固定 DeepSeek Flash 做一次静态审查，无重试、无 Pro 回退。报告须人工核实，模型不会替代浏览器测试。原有任务卡片独立审查流程保留。
