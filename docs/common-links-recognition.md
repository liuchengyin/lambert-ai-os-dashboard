# 常用链接识别优化

- 锁定只限制改名、删除和拖动，不限制添加。桌面和手机的搜索栏都保留添加入口，分组内也可直接添加。
- 粘贴地址后450毫秒自动识别；常见 DeepSeek、Google 页面先按精确域名和路径识别，其他网站通过同源后端读取 HTML 标题和网站声明图标。成功后名称只读，以识别结果保存。网站阻止抓取或网络不可用时才开放手动补充。
- URL变化取消旧请求，并校验版本，避免慢响应覆盖新网址；识别中不能保存，取消弹窗后不写回旧响应。保存失败保留草稿及原始链接数据。
- 旧链接的名称、备注、扩展字段保留。已知站点显示本地清晰图标，不再拉伸旧低分辨率 favicon。其他站点优先 SVG/高清图标，失败显示清晰文字标识，不显示破图。
- 链接识别不调用 AI，不产生 DeepSeek Token 费用。
- 后端只允许公开 HTTP(S)、标准端口，不带网站登录 Cookie；校验 DNS 并固定连接地址，每次跳转重新检查，拒绝私网、回环、链路本地和混合 DNS 结果。限制页面262144字节、3次跳转、6.5秒超时、并发4个；短期缓存最多100条。

## 图标来源

- DeepSeek：官方平台 HTML 声明的 `https://fe-static.deepseek.com/platform/favicon.svg`。
- Google：官方静态资源 `https://www.gstatic.com/images/branding/googleg/1x/googleg_standard_color_128dp.png`，本地保留128像素源图，以42像素显示。

图标仅用于识别书签指向的网站，不表示与网站运营方存在合作关系。
