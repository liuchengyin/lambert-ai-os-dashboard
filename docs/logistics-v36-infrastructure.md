# Lambert Logistics V3.6 信息流/数据流预留结构

房子由工作台搭建，业务事实由用户填。每个操作节点有统一五类可选配置槽：

1. 事件/内部日志与持久化记录：事件码、日志位置、记录表名、关联键。
2. 推送路由：待核实 / 仅内部留痕 / 满足规则推送 / 对外推送；填写判断条件与接收端。仅记录用户所知，不实际发消息。
3. 数据来源：允许多条 OMS、EDI、TMS、轨迹、其他数据表，含表、关联键与消费字段。
4. 数据看板与 SLA：指标名称、口径、时间字段、目标及看板入口。不计算指标。
5. 任务看板：触发条件、目标看板、责任人与处理动作。不创建任务。

主画布新增统一的基础设施骨架，节点卡片显示已配置的层数，节点详情显示具体线路及配置按钮。业务异常分支仍是业务路径，信息流配置独立于分支，不将内部日志等同于对外物流轨迹。结构中所有位置在未核实时均为空白或标记待配置。

使用可选 node.infrastructure，旧数据不迁移。保留已有字段/未知扩展和旧版本草稿、发布及回滚机制。真实 OMS/EDI/数据库、SLA 计算器、任务系统接口均未接入。
