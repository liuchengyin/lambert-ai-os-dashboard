# App 音频 Tab（开发验收）

基线 main b705f8f；分支 feat/android-audio-tab。用户本轮要求开发，尚未合并生产。

音频 Tab：多选导入 MP3/M4A/WAV，每文件200MiB，音频库最多200条（事务内校验，防并发超限）；整套分组，逐条改标题、备注与摘要；真实播放、倍速、回退3/7秒、前进3秒、进度记忆、单条循环/整套循环/A–B循环。切换任务/项目/复盘不停止播放器。

Web与App共用 shared-sync/audio-store.mjs，保留原 english-audio-store.mjs 导出入口、数据库版本1和旧记录，不迁移或清除数据。App使用相同账户隔离命名，音频Blob仍仅在设备IndexedDB。旧网页UI未添加批量导入和备注，当前新增能力属于App Tab；不能将其描述为网页也已升级。

原生使用Media3 1.5.1 ExoPlayer + MediaSessionService，媒体前台服务/通知栏/音频焦点/拔耳机暂停/CPU唤醒锁，后台播放不依赖WebView计时器。A–B由服务线程循环，后台进度由私有SharedPreferences保存。通过系统文件选择器临时授权导入，不申请麦克风、相册或存储全盘权限。

原生文件按账户分目录，每账号最多4GiB后台文件；首播以96KiB块复制IndexedDB音频，整套播放先准备当前组全部文件。原始Blob保留以避免丢失，实际会占用双份空间。仅固定UUID路径；大小、完整性、空闲空间、200条限制；临时文件原子改名、异常及Activity销毁清理；账户切换停止播放、取消导入，带epoch拒绝陈旧命令。原生0.2.7/versionCode18；新APK内置页面不会被较老生产云包覆盖。

## 验证

本地 tests/mobile-audio.mjs：真实WAV播放、批量导入、3/7秒边界、倍速、AB、备注/标题保存、切换Tab持续播放、刷新恢复、320/390/768布局、事务内200上限并发、ID保护、原生桥接模拟（整套队列、分片、切换曲目不被旧状态抢回）通过。原生桥接模拟不等同Android后台验证。

43项数据/账号/RLS测试通过。GitHub Android编译/lint及浏览器音频测试通过（40978647585）。Android 15模拟器2项真实仪器测试通过（40978696340）：播放后退后台并熄屏，2.5秒后仍播放且进度增加；账号切换停止；未完成分片导入在失败/切号后无最终文件。模拟器不等于vivo真机验收。独立工作流固定源提交构建，不复制或公开签名私钥。

新Tab相关旧测试明确从3个入口更新为4个，原交互断言保留。旧主分支最近新增lib/link-recovery.js但本地预览白名单未更新，导致桌面回归启动失败；本次仅补该公开资源白名单，不开放服务端lib。任务流转、移动任务手势/复盘草稿、导航一致性与core-space本地回归已通过。
