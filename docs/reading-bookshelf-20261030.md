# 每日阅读：7 本书架

- 本地 PDF 原本只有 object URL，刷新即失效。新实现将文件保存在按账户隔离的 IndexedDB，书架与笔记存储独立。
- 最多 7 本，50 MB/本，仅 PDF。书封由书名生成，原有链接阅读收进折叠项。模式按钮缩小，顶部手填进度不再占行。
- PDF.js 4.10.38 按页显示，翻页保存位置；同设备缓存文件与会话内解析结果，换设备首次需下载。不承诺首次或大文件一律秒开。
- 云端独立 lambert_books 表，slot 0–6 与(user_id,slot)唯一约束保证跨设备七本；私有 lambert-books bucket。RLS 校验 auth.uid 与目录。浏览器只使用已有 publishable key 与经过验证、固定的用户 access token。
- 文件保存与上传状态区分；上传失败保留本机原件/云端预留位，允许重试。离线进度先本机保存，联网后重试。远程满额时保留额外的本机待上传文件，不静默删除。
- 移除书籍需确认，仅删除所选书籍，不修改读书笔记、任务、项目或链接。

## 发布顺序

1. 检查并应用 `supabase/migrations/20261030092441_reading_bookshelf.sql`，核对私有 bucket、RLS、7 槽唯一约束。
2. 合并并部署。Vercel 先运行 build-reading-assets.py，从固定 npm 包生成同源 PDF.js 与 worker，SHA256 不符立即失败；用户打开书籍不依赖外部 CDN。
3. 用测试账号验证文件上传、重新登录/换浏览器下载、页码同步、账户隔离与移除。不得用清库或删除用户业务记录验证。
