# 刷新旧界面与同步安装包

## 原因与修复

网页初始 HTML 是早期 Top 3 / 当前主线 / 快捷入口布局，bootstrap 随后串行加载增强模块，project-v4 再动态加载样式与仪表盘。请求慢时旧脚手架会先显示，已通过拦截 project-v3 请求复现。

仅在桌面 HTML 添加启动状态，旧脚手架在核心模块及嵌套同源资源完成前不可见；失败显示重试，不回到旧界面，不清理用户数据。预加载只并行获取文件，脚本仍按原顺序执行。可选第三方编辑器不阻塞核心页面。账号网络请求仍在本地界面准备完成后启动。

验证：慢网旧界面不可见、当前导航和 TaskCenter 挂载完成后展示、核心脚本失败重试、本机数据保留；使用原同步浏览器流程做兼容回归。
