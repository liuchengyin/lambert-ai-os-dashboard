# V2 本地组合安全备份（待发布）

## 目的
画Master 云同步已经确认能跨站点恢复，但工作区 JSON 与画Master IndexedDB 图纸依旧由不同入口维护。现有「我的账户 → 下载工作区备份」并不包含图纸或 PDF 二进制。为降低误以为所有内容都备份的风险，新建一个**明确范围、只读、纯本地下载**的组合备份。

## 新入口
画Master → **下载安全备份**：下载 `Lambert-safe-backup-YYYY-MM-DD.json`。

**包括**
- 原始未登录访客任务/项目/复盘/文档键值（原始 JSON 字节）。
- 当前启用账号范围内的工作区 journal 底稿、未发送批次、冲突及账号私有文档缓存。
- 当前设备画Master 图纸（完整 XML 和文件属性）、回收站图纸。
- 账号 UID 与备份时间，用于后续核对来源。

**不包括**
- 阅读 PDF 二进制、音频/视频文件。
- 画Master 已保存的历史 revisions / IndexedDB `backups` 存储区。
- 仅存在其他设备或云端的图纸快照。
- 浏览器所有其他未知扩展本地状态。

## 安全规则
- 只读本机 localStorage 与画Master IndexedDB；不上传网络、不写入用户存储、不更改 Supabase 权限或业务数据。
- 检查开始和下载之前的账号一致性；遇到账号切换、图纸不合规、读库失败则拒绝生成，而不是生成不完整文件。
- 这个 JSON 含个人任务、笔记、图纸内容，视为敏感个人备份；建议存储在加密磁盘，勿发到公开网盘或聊天。
- **当前只支持导出，不支持自动恢复**。下载成功仅代表完成文件生成，需确认浏览器实际保存文件、文件可读取及源账号一致。恢复须另行设计「预览、选文件、非覆盖导入、重复与冲突报告」，通过测试后再发布。

## 验收
`node --test tests/portable-safety.test.mjs`：
- 访客原始数据、正常图纸与回收站均保留；
- 登录用户只导出所属账号空间，不混入其他用户缓存；
- 导出途中账号切换安全终止；
- 不合法图纸拒绝导出且无修改。

生产部署之前跑 Netlify/Web 主 CI；线上由 Mac 手工验证下载以及 JSON 结构，不提交用户私人备份到 GitHub。
