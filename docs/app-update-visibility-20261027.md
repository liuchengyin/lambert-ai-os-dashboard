# App 版本和更新感知

- 任务、项目、复盘页面顶部常驻版本入口，点击直接打开账户中的“版本与更新”。更新已下载时入口显示“新版本 · 待重启”。
- 账户页始终显示当前页面版本、本版改进、更新状态和检查按钮，未登录也可使用。检查更新不禁用账户的其他操作。
- 版本号由构建时间自动生成，采用上海时区，例如 2026.10.27.132248。当前 HTML 携带构建标记，与该次更新包内的 release.json 一致；安装包内置页面也在打包时生成标记。
- 原生接口返回的 release 是“已安装或已下载的最高版本”，不能用它覆盖当前正在运行的版本。下载完成后需要完全退出并重新打开 App，本期不添加伪重启按钮。
- 检查、下载、待重启、读取失败和可重试状态有明确文案；移动网页版只显示网页版本说明，不调用原生更新接口。
- 保留移动网页版 Service Worker，仅在 Android 页面包中移除它。连续构建不会叠加旧版本标记。
- 后续发布如涉及用户可感知的变化，请更新 mobile/update-notes.json；版本号自动生成，不需要手改日期或数字。

验证使用模拟原生控制接口与生成的真实页面 ZIP，覆盖当前/待启用版本分离、状态变化、失败重试、320px 布局、账号与待上传数据保留；不等同于手机真机验收。原生安装包更新机制与权限不变，本改进通过现有页面更新能力交付。
