# Lambert OS 物流知识库 V3.1 · 可配置操作与轨迹关联入口

## 本期交付（独立 Preview）
1. 四层业务架构保持：仓/干/关/配分类 → 业务模块 → 子环节 → 操作块；大模块可改名，中模块已可改名，操作块标题可在编辑弹窗中改名。
2. 删除 L2/L3/L4：需先解锁，弹窗列出受影响的操作和关联，删除仅进入当前草稿；回收站保留模块、子模块、节点、字段、证据和有关分支快照，可按依赖顺序恢复；保存草稿不修改已发布版，正式确认发布后才生效。历史快照继续可回滚。
3. 纯黑白主题：仅覆盖物流知识库页面，不修改其他 OS 模块；白底、灰色线条、较大字号与更高对比度。大中小模块原有自定义色保留；没有自定义色时使用黑灰默认色。
4. 操作块独立色标：可编辑自定义颜色/恢复默认。数据字段使用可选 `node.color`，旧节点兼容。
5. 操作备注：`node.note` 字符串；操作详情和小操作卡片可见摘要。
6. 搜索标签与操作码关联入口：`node.tags: string[]`、`node.operationCodes: string[]`，支持按模块名、节点名、备注、标签和操作码检索。**仅储存用户输入的原始码表候选值，未自动映射到真实 OperationCode / 原始轨迹码 / 标准轨迹码**，不虚构关系，后续接入码表数据库。
7. 主流程、异常流程、普通分支：主线继续按节点顺序显示，阶段「＋ 分支 / 异常」可选择当前阶段的源操作→已有目标或新建目标操作；新建默认作为分支节点；异常红色虚线、普通分支蓝色线条（业务语义颜色），不被节点颜色覆盖。主流程黑灰实线。
8. 去掉大模块、阶段和小节点的前进后退顺序控制，仅保留大/中/小模块拖动与业务连线箭头；操作详情的跨模块／跨阶段移动选择器仍保留，便于移动端操作。

## 数据安全
- 未更改原 `lambert_logistics_knowledge_v1`、`lambert_logistics_versions_v1` 键结构，新增均为当前发布/草稿数据的可选字段 `trash`、`note`、`tags`、`operationCodes`、`color`，schema 仍为 1。
- 任何删除先进入草稿回收站；不提供对回收站的永久清空操作，也不自动清理版本历史。
- 恢复中模块时保留原始节点相对顺序锚点，针对删除其他节点后的恢复新增回归；遇到相同 ID 冲突安全拒绝覆盖，并保留回收站中原始快照。
- JS 显示用户输入使用 textContent，操作码仅作为标签记录；不依赖未验证的 OMS/TMS/EDI 数据。
- 仍为当前账号/浏览器本地版本，不支持跨设备自动同步或数据库级编辑锁。
- 操作模块与轨迹事件、指标、结算的自动关联未上线，仅预留结构。异常回到主流程的复杂会合/跨大模块图形连线仍属后续项目。
