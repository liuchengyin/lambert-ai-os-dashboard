# 工作台可靠性改进交付说明

对应四项高优先级需求：W1 网页保存/同步状态、W2 任务写入统一、A1 App 同步与冲突处理、A2 完成/归档撤销。

- 任务写入沿用 app.js 的 set('tasks', ...) 作为统一持久化边界，失败恢复最近成功保存的任务快照。persistTasks 负责成功后的关联刷新，移除 dashboard-v5/project-v3 对该函数的覆盖，保留兼容委托。
- 两端使用共享状态提示，区分本机保存、待上传、离线、冲突及已同步。保存失败通过共享事件显示，冲突错误包含记录 ID/类型以定位账户中的对照卡片。
- 用户明确选择冲突版本后，重新读取账号隔离快照并更新网页/App 当前视图；复盘采用选定版本，不重新覆盖为旧草稿。其他记录未提交的输入继续保留。
- App 完成/重开/归档成功后提供 5 秒撤销。撤销只恢复此次修改的字段，保留之后的备注和步骤。重复任务生成的后续任务只有完全未修改时才可随撤销移除；过期、账号切换、删除及后续状态变化会阻止恢复。
- 既有删除撤销继续沿用，不扩展回收站。既定完成 1/4、删除 1/2、直接归档手势不变。

本分支基于 PR #62 的修复继续开发；提交/PR/预览不代表生产已发布。已有真实账号冲突仍由用户选择版本。

验证：8 项开发工具、34 项数据保护检查；网页任务流转；完整任务中心三视图/项目/复盘；App 六组交互含真实触摸；真实 SDK + 模拟云服务的两端登录/上传/重连；新增两端同步状态/冲突定位/明确选择版本后视图刷新、完成/触屏归档撤销、重复任务与过期/账号保护测试。以上本地验证不等同于真实云账号或 Android 真机验收；Android 页面资源已打包，原生编译由 CI 验证。
