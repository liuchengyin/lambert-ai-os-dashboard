# Flash 独立审查与任务卡片残留清理

原始审查：GitHub Actions 39002830337，源码提交 87657d7bcb72960865c062d29b7b5a3d93848f4e。请求模型和返回模型均为 deepseek-flash，单次请求，输入16334 tokens、输出1267 tokens。静态审查不代表运行测试。

## 人工核实

1. 带截止日期的卡片可以复现自触发 DOM 更新：ui-polish-v3 写入隐藏的倒计时文字，引起 childList 观察器重新执行；task-board-v6 同时监听整个 document 并调度增强，扩大了更新范围。无截止日期时不一定复现，不能表述为所有卡片始终循环。
2. 两套标题包装器、隐藏倒计时和每分钟定时器没有当前可见功能；紧凑单行需求已经不显示这些内容。CSS 中存在多次定义后再隐藏和覆盖的历史叠加。
3. .matrix-preview 的删除和 CSS 隐藏重复，但不是主要性能问题。Flash 建议中的 #taskBoard 并非现有实际容器，不直接采用；移除已无功能的整套 V6 DOM 增强及加载入口，保留单一 CSS 隐藏规则。

## 最小清理

- 卡片由 dashboard-v5 直接渲染标题和当前状态操作，详情仍保留在任务数据、编辑器、搜索及筛选逻辑中。
- 移除 ui-polish-v3 内仅处理任务卡片的旧增强函数和定时器，保留其其他模块行为与拖拽样式。
- 移除不再需要的 task-board-v6.js 及其唯一加载入口。任务卡片样式整理到 task-board-v6.css，保留必要的共享主题边框覆盖。
- 不实施尚在脑暴中的两列看板，不改现有状态、存储内容或 AI 助理未发布功能。

## 运行证据

同一浏览器、相同带截止日期的任务、页面稳定后，观察单张卡片500毫秒内 childList/subtree 变动：清理前300次、清理后0次。隐藏倒计时节点由1个变为0个。此计数为测试环境复现结果，不是所有机器上的固定性能指标。

回归增加：带日期卡片不再生成旧包装器、角标或隐藏倒计时；闲置期间没有由旧倒计时引起的节点更新。既有拖拽、四象限颜色、圆形完成勾、编辑退回和数据刷新测试保留。
