# 物流知识库 V3.2 · 点击小模块直接编辑

## 改动
- L4 小操作块采用统一入口：**点击任意操作卡 → 立即显示可关闭的详情弹窗**。不用向下寻找隐藏在长流程画布底部的详情。
- 详情标题右侧直接固定三个操作：**编辑名称 / 编辑内容 / 删除模块**。非编辑状态查看信息不受影响。
- 默认锁定状态下，详情只读并提供明显的「解锁编辑」入口；解锁前后**保留当前选择的操作 ID**，不会跳到该模块的第一个节点。
- 编辑名称打开轻量弹窗，只修改 `node.title`。操作 `id`、`stageId`、标签、备注、轨迹码候选、事件分支 ID 和关联信息都原封不动；名称变化立即反映到主线与分支的卡片。
- 编辑内容复用既有完整编辑器（备注、标签、码表、节点颜色等）；保存后回到原节点详情。用户取消/按 Esc 返回详情，无误提交。
- 删除使用既有回收站、影响确认与草稿隔离机制；从详情删除后关闭弹窗，不重复创建节点。
- 搜索结果、异常分支操作块、数据关系 Tab 中的操作和全链路 B 模式中的小操作都能使用同一详情入口。
- 自适应移动端宽度，三个动作在手机上仍可点击。
- 沿用 `lambert_logistics_versions_v1` 的草稿、确认发布、历史回滚；旧 `lambert_logistics_knowledge_v1` 不进行额外写入，其他 OS 数据不变。

## 范围
只调整物流知识库小操作块的“点击与编辑”交互；大/中模块已有改名和删除入口保留，不在本轮重排其它产品功能。V3.1 仍未发布生产，V3.2 从该预览分支派生。未经用户确认，不合并至正式版。
