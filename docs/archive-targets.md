# 阅读归档位置设置

网页每日阅读 → 归档位置设置：添加名称和飞书知识库节点链接，为每日阅读、插件笔记分别设置默认位置。保存时输入现有AI入口密码，密码不会存入配置。配置使用现有Upstash Redis与AI_ACCESS_PASSWORD，不新增凭证。

当前支持 https://租户.feishu.cn/wiki/节点ID，暂不支持云盘文件夹。目标节点需给原飞书应用编辑权限，否则归档会返回权限提示。

已有文档不会自动搬迁。选择新位置后重新归档会在新位置新建，同位置继续更新。未改配置前兼容原节点；每日记录旧入口维持原位置。

插件：下载 downloads/lambert-reading-extension-v0.2.3.zip，解压到现有插件文件夹；chrome://extensions 打开开发者模式，点原插件“重新加载”。也可解压新文件夹后加载已解压的扩展程序。插件侧栏有位置选择器，“添加/修改”打开工作台设置；位置会从服务端读取。

检查仅使用模拟接口，不向真实飞书写测试文档。
