# 物流知识库 V3 · 发布与全链路总览

## 产品约束
- **默认锁定**：只读可查看旧的操作和信息流，禁止误拖、误改、误连线和更改颜色。必须主动点击“解锁编辑”。
- **草稿隔离**：解锁后修改只在页面内存，需主动“保存草稿”才写入版本记录。刷新时未保存的修改不会生效，页面离开会弹出提示。保存草稿不更新全链路总览。
- **发布审批**：保存草稿 → 点击确认发布 → 明确确认框 → 版本号 +1，写入发布快照，自动锁定，总览读取新发布内容。
- **历史回滚**：历史版本下拉选择旧发布，确认回滚后创建**新的**发布版本并保留旧历史，不把过去版本覆盖或删除。若存在已保存草稿，回滚前会明确提示清除。
- **新 Tab 全链路总览**：两个模式 A 宏观模块（默认）和 B 完整流程（按模块、子环节、操作顺序展开），默认只读，点击可定位业务模块操作。支持条件分支和异常分支的可见标记。
- **主流程/异常流程/普通分支**：主流程按操作顺序展示，新增连线可以明确设为异常或普通分支。正常流程未确认时不假设自动触发关系。

## 数据安全与兼容
- 旧数据 `lambert_logistics_knowledge_v1` 只读，不修改也不执行自动覆盖式迁移。
- 新独立版本数据键 `lambert_logistics_versions_v1`（沿用原 OS 的 `LambertPrivateStorage` 账号隔离机制），一次写入包含 `published`、`draft`、`history`，避免多键更新一半成功一半失败。
- 首次进入采用旧 V1/V2.3 的内容作为**内存中的 V0 基线**，**不自动写入**新键。第一次保存草稿才真正落盘；第一次发布会保存 V0 快照。
- 若新版本数据结构损坏，进入只读保护，绝不覆盖已存在的版本记录。
- 历史版本无限制保留，存储空间不足会拒绝保存并保留当前数据，不会静默丢失历史。
- 未做云端版本同步，多端设备/不同预览域名无法自动共享版本状态；重要数据应通过 JSON 导出另行备份。
- 旧项目、任务、复盘及其他 OS 数据存储无变更。
