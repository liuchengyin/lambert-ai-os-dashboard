# Lambert AI OS · 第二大脑 V1

## 定位
作为现有工作台的新增一级入口「第二大脑」，不替换项目、任务、每日复盘、常用链接和阅读模块。

## 架构
- 现有业务数据（只读）：浏览器 localStorage 的 `projects`、`tasks`、`daily_reviews_v2`（缺失时读取 v1）。
- 第二大脑独立写入：唯一新业务 key 为 `lambert_brain_notes_v1`，结构为笔记数组（id/title/body/category/projectId/createdAt/updatedAt）。
- 索引：每次刷新从原始存储读取，构建临时节点（项目/任务/复盘/笔记）及关系边，不写回原业务数据。
- 关系：项目→任务（projectId 或项目名称）、任务→复盘（taskIds）、项目→第二大脑笔记（projectId）。
- 界面：筛选、全文包含搜索、节点图预览、关联记录、笔记增改。
- 独立笔记 JSON 备份：点击「导出脑笔记」下载本地笔记（含扩展字段）；**不包含项目、任务、复盘与其他 localStorage 数据**。
- AI：V1 不调用远程模型、不上传业务数据。后续 V2 加入检索结果与明确来源、手动确认写入。

## 重要安全约束
1. 禁止在第二大脑模块中写入、迁移、删除、覆盖旧 keys。
2. 无网络同步、无数据库迁移、无 AI 自动生成覆盖现有数据。
3. 不直接从 GitHub 获取用户笔记；GitHub 仅管理前端代码。
4. 第二大脑数据仍是浏览器本地数据：换设备/浏览器不会同步。账号、Supabase、云端安全存储单独设计。
5. PR 留在开发分支，现有数据备份未完成核验之前，不得自动合并或发布到 main。
6. 生产发布前先检查站点原域名的历史 localStorage 备份是否能恢复，并完成手动 UI 回归。

- [ ] 第二大脑显示已有项目、任务、复盘；没有数据也正常展示
- [ ] 新建、保存、编辑第二大脑笔记成功，刷新后仍在
- [ ] 笔记关联项目后可查看关系
- [ ] 搜索与类型筛选正常；图谱节点点击可定位详情
- [ ] 导出 JSON 能被解析且包含所有现存第二大脑笔记；导出不触碰原始项目/任务数据
- [x] 11 项轻量 DOM 行为模拟验证（不等于真正浏览器端验收）
- [ ] 页面刷新停留在第二大脑 tab；主导航侧栏折叠无回归
- [ ] 移动端尺寸无溢出阻断
- [ ] 不向 AI 模型传输笔记，浏览器网络请求无新增模型调用
- [ ] 基线手动数据备份、恢复演练及批准后才允许 merge

## 测试命令
本地启动 `python3 -m http.server 8000`；安装项目所需 Playwright 后执行 `TEST_BASE_URL=http://127.0.0.1:8000/ node tests/second-brain-ui.mjs`。
该脚本使用测试浏览器上下文和虚拟数据，不读取正式用户的浏览器资料。
