# V2 安全恢复：只新增缺失的画Master 图纸（独立开发，未发布）

## 范围
在画Master「校验备份文件」成功后，显示本机缺失图纸、缺失回收站、相同以及冲突数量。
仅在用户再次点击「恢复缺失图纸」并通过确认弹窗后进行写入。

- 执行范围：**本机 IndexedDB 画Master files / trash 两个存储区**。
- 只新增 ID 不存在的备份文件；保留原始 XML、标题、创建和更新时间。
- 文件 ID 已在本机现有图纸 **或回收站** 存在：均跳过，不覆盖、不移动、不复活。
- files 与 trash 使用同一个 IndexedDB readwrite 事务，防止半恢复；再次导入不会重复。
- 校验备份账号 UUID，进入恢复前重新读取本机图纸与回收站；如果预览后内容改变则要求重新校验。
- 不修改任务、项目、复盘、阅读笔记、PDF、音频、任何 Supabase 云数据或已有图纸历史版本。
- 不自动上传恢复的文件；需要后续主动点「云端同步图纸」。

## 限制
当前工作区备份仅提供只读校验，不进行任务/项目/笔记的 JSON 恢复。图纸恢复是非覆盖的最小安全闭环，不代表全部数据均具备灾难恢复能力。
用户务必在恢复前另存当前 Mac 数据和 .drawio 备份。不建议将包含个人数据的 JSON 文件发到聊天或公开网络。

## 测试
- `tests/portable-recover.test.mjs`：缺失、冲突、回收站、重复 ID、重复导入的纯计划逻辑。
- `tests/master-files-v2-ui.mjs`：真实 Chromium IndexedDB 中同一事务内恢复、冲突不覆盖、回收站不复活、二次导入幂等，以及本地 JSON 备份选择和确认式恢复 UI。
- 需等待 Web Release / Netlify / 数据同步 CI 通过后再讨论发布。生产环境真实账号恢复需用户本人显式点击确认，不在 CI 中接触真实数据。
