# 醒来后只需做这些

目标：网页和 App 使用同一邮箱账号，任务、项目、复盘同步。代码和测试先准备，不会自动导入或清空你现有的浏览器 / 手机内容。

## 1. 建 Supabase 项目

打开 https://supabase.com/dashboard ，注册或登录，创建自己的项目，记住数据库密码即可，不要发到聊天。不要为了这次接入升级付费套餐。区域先按实际手机网络测试选择，后续联调要在常用网络下验证连通性。

## 2. 提供两个公开配置

在项目的 Connect 或 Settings → API Keys / Data API 找到：

- Project URL，形如 `https://xxxx.supabase.co`
- Publishable Key，形如 `sb_publishable_...`

这两个是公开客户端配置，可提供给 Codex 进行部署配置。**不要提供数据库密码、Secret Key、service_role 或 Supabase 账号密码。**此实现主动拒绝旧版 JWT 形式的 key，以免混入高权限密钥。

拿到这两个公开值后，Codex 负责在 Vercel 的预览环境配置：

```
LAMBERT_SUPABASE_URL
LAMBERT_SUPABASE_PUBLISHABLE_KEY
LAMBERT_PUBLIC_SITE_URL
```

第三项是固定的测试站点来源（不含路径和尾斜杠），真实邮箱回跳必须进入这一来源；同源账号状态才能被网页读取。完成测试后再配生产环境。预览被 Vercel 登录保护时，邮件回跳还要确保本人能打开该来源。

## 3. 执行已准备的建表 SQL

Supabase → SQL Editor，新建查询，粘贴仓库 `supabase/migrations/202610190001_shared_workspace.sql` 全文并运行一次。此 SQL 为新项目创建独立表，不修改已有工作台数据。若已有同名表，先让 Codex 检查，不重复执行。

这一步需要你登录 Supabase 后操作；如果之后提供可用的 Supabase 管理连接，可由 Codex代执行。无需把数据库密码发来。

## 4. 配邮箱回跳地址

Authentication → URL Configuration：

- Site URL：部署的固定测试站点来源。
- Redirect URLs：`https://该站点/account.html`，精确到此页面。

Authentication → Providers → Email：启用邮箱与密码，保留邮箱确认。默认邮件服务存在收件人及频率限制；个人初测可先用组织成员邮箱，正式稳定收信应配置自己的 SMTP。SMTP 账号和密码只填 Supabase，不发聊天。

## 5. 收一封邮件做最终联调

在测试网页点“登录”→“注册账号”，填自己的邮箱和密码→打开验证邮件→回网页登录。App 使用同一邮箱密码登录。App 注册后的验证链接会在手机浏览器中打开，验证后返回 App 用密码登录即可；这版不依赖 App 深链。

登录后先显示“尚未启用同步”：

- “使用云端工作台”：打开账号已有内容，本机访客原始数据不动。
- “检查并导入本机数据”：先展示新增、相同、冲突数量；下载备份并确认后再导入。冲突默认保留云端，本机原始内容及备份保留。

然后测试手机新增任务→网页出现，网页完成→手机同步，分别修改项目、复盘。网页 / App 目前在写入后、联网恢复及前台每 30 秒尝试同步；发现云端内容变化显示刷新提示，点一下刷新以避免打断未保存的输入。

## 不需要你处理

不用自己改前端、创建数据库字段、写接口、编译 App。Codex 会处理 Vercel 配置、代码整合、检查、打包和发布。旧 App 不含网络能力，因此首次接入登录需要覆盖安装一次同签名的新包；保持原应用 ID 与本地来源，保留原本地数据。未完成配置前不分发可误认为已同步的安装包。

## 当前边界

登录只认证用户，不会替代现有 AI / 飞书接口各自的鉴权；这轮共用数据范围仅任务、项目和每日复盘。其他个人工作台模块仍保持原状。

## 复盘归档到飞书（10 月 20 日接入）

现有飞书应用和归档目录已在线检查正常，不需重新创建机器人。把准备登录的邮箱告知 Codex，由 Codex 在对应环境设置 `LAMBERT_FEISHU_ALLOWED_EMAILS`，避免其他注册账号写入你的知识库。

使用流程：手机保存复盘 → 联网同步 → 网页打开同一天复盘 → 点击“归档到飞书”。系统先完成云同步，再按该账号的云端复盘及任务完成状态生成文档，归档至现有“每日记录”默认位置。相同内容返回原快照，修改内容后保存新快照，原文档保留。归档链接也随复盘同步。

如显示“归档结果尚未确认”，先打开飞书目录检查，不要反复点击或手动清空凭据。服务端会保留待确认记录，防止超时重试生成重复文档。
