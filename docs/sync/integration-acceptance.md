# 网页与 App 同步验收

范围：任务、项目、每日复盘；不更改任务界面或加入 App 云更新。

## 使用步骤

1. 在有旧数据的网页浏览器打开「我的账户」，使用邮箱登录。
2. 选择「检查并导入本机数据」，核对新增、相同和冲突数。
3. 导入前会自动在本机另存完整备份，保留原始数据。电脑可再点「下载完整备份」另存 JSON。
4. 勾选确认再导入；同 ID 不覆盖云端，已删除的云端记录不会因导入重新出现。
5. App 用同一个邮箱登录，选择「使用云端工作台」。若手机也有独有旧数据，先检查导入手机本机数据。
6. 两端新增或修改后查看「我的账户」同步状态。新云端数据通过页面刷新提示加载，避免覆盖正在填写的表单。
7. 有冲突时，账户页选择保留云端或使用本地；处理前两份内容均保留。

原始本机数据不会自动跨设备出现，首次必须在原浏览器显式导入。退出账号回到本机模式，旧数据仍在。不要卸载 App、清除应用数据或清理浏览器站点数据。

## 备份内容

v2 JSON 包含旧本机键原始字节、账号当前有效快照、云端缓存、待上传队列及冲突记录；不导出认证会话或密码。账号缓存损坏时仍保留账号原始字节和异常提示。自动备份与数据同在设备上，不能代替异地下载备份；Android 当前 WebView 没有文件下载桥，自动本机备份可用，下载文件请优先在电脑进行。

## 自动化证据

- Node 数据、注册、PostgreSQL RLS、版本冲突、幂等、删除墓碑、账号隔离和飞书边界测试。
- 两个独立浏览器上下文、真实打包的 Supabase SDK、模拟托管服务：手机新增上传→网页读取完成→手机读取；云端启用后的导入、重复导入；预览期间远端变化阻止旧预览提交；离线项目与复盘补传→网页读取。
- 自动化不会使用真实用户账号、发邮件或修改生产用户数据。

## 真账号与手机验收（待用户）

1. 注册收验证码、设密码，网页和手机用同一邮箱密码登录。
2. 网页先用一条测试任务验证同步，再核对原有任务、项目、复盘数量后批量导入。
3. 手机新增一条任务，电脑刷新提示后出现；电脑完成它，手机刷新提示后显示完成。
4. 手机断网新增项目或复盘，关闭再打开 App，应仍保留；联网后电脑可以读取。
5. 不同设备同时修改同一任务，显示冲突并可选择内容。

当前 Android 0.2.0-test 已包含原有共同同步协议，可以从网页导入后读取云端。此分支新增的完整备份和导入防护仍需打入后续安装包；发布网页不会自动改已安装 App。尚未加入 OTA，不应宣称此分支已解决 App 云更新。
