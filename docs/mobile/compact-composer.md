# 移动端紧凑创建面板

范围：先实现任务面板，再由项目复用。桌面布局、云数据库、账号体系保持现状。

- 任务按截止时间升序显示，未设/无效日期放最后；仅改变显示，不重排存储。日期带时区时按实际时间比较。
- 新任务为底部标题/描述输入及日期、项目、标签、优先级图标；没有取消按钮，遮罩、Escape、安卓返回可以关闭。保存失败保留输入。
- 旧任务详情保留步骤提升/删除、完成重开、日期、关联项目、重复和备注。
- 项目复用创建面板，支持起止日期、完成标准、分类、任务关联、状态。原有字段、未知字段及未改日期的时分保留。项目与任务用共同存储桥 writeMany 本地原子保存，不影响未改任务。
- 全局任务/项目大标题22px，任务/项目名称17px、同字体。项目详情使用名称字号；列表任务对勾使用挺直SVG。App显示名、移动网页标题、PWA名称为 Lambert，包名不变以保留覆盖安装能力。
- 安卓新旧返回键都优先关闭网页弹层，正在处理的返回操作不重复提交。

DeepSeek Flash一次静态审查，输入10466、输出466、合计10932 tokens，无Pro。对其两项发现核实：项目map已只对selected或was为真的任务改关联；MobileNavigation.back关闭弹层后返回true，不会继续退出。另补强项目无变化任务不更新及安卓返回防重入。
