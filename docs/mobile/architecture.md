# 手机端 V1

范围：今日、任务、项目看板、复盘。独立 /mobile/ PWA 入口；桌面网页不变。先交互预览，再验证安装与离线，最后封装 Android，不能把 PWA 宣称为原生 APK。

DeepSeek Flash：手机四页交互及样式。GLM 4.7 Flash：本地保存、待同步队列和测试。Codex：边界、整合和基础验证。

数据：同一站点沿用 tasks / projects / daily_reviews_v2，保留已有字段。手机操作先落本地，再记录待上传标记。离线 shell 由仅作用 /mobile/ 的 Service Worker 缓存，首次需在线打开。

同步阶段：当前桌面没有任务云存储；本版不能宣称跨设备自动同步。后续复用现有服务端会话认证与 Redis，按记录建立版本号、mutationId 幂等和 tombstone，写入冲突保留双方版本；确认服务端持久化后才移除本地队列。同一设备桌面/手机页可共用同源数据，但不同域名预览、不同设备不能共用 localStorage。现阶段队列是脏键标记，不是可上传的最终操作日志。

Android 阶段：手机交互验证后封装本地 Web 资源；必须先接通认证和同步，再提供正式 APK。离线模式不可依赖远程页面加载。
