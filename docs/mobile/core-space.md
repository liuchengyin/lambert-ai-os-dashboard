# 核心信息优先的手机界面

去掉品牌门头，账户入口保留在底部。任务页直接呈现日期/项目筛选与任务，保留已完成折叠与新增加号。项目列表只保留标题、类别、日期和百分比/细进度条；项目新增复用任务浮动加号，放在根容器避免列表溢出裁切。项目下钻标题即编辑入口，移除新增按钮和重复编辑按钮，统计改为小型彩色信息条。

复盘提供昨天、今天、明天与任务共用日历；日历复盘模式不显示时间/清空。目标进度在标题右侧灰字显示，目标项目筛选为多选，不自动批量选入任务，已完成任务不能新增为目标。已有目标完成后划线并计数。勾选目标、完成任务、切日期和返回详情时保留填写草稿；日期切换保存有内容的当前复盘，不制造空白日期记录。

保存后出现飞书归档入口，先同步云端、再调用原有 Bearer 身份与邮箱权限校验的归档接口，成功合并链接凭据并刷新复盘；请求期间的新输入保留，失败不清空正文。App 网络白名单仅新增固定生产归档端点；预检仅放行固定 appassets HTTPS 来源；飞书链接经用户点击后用外部浏览器打开，不在 WebView 加载任意网站。

任务步骤使用加号提示和一行输入，回车/离焦提交为待保存步骤，连续输入不需要添加按钮；原有完成、提升、删除、最终保存逻辑保留。

验证：认证/数据/归档与 CORS 单测，原有浏览器邮箱/双端同步流程并增加手机归档路径，新界面 14 类交互（多选、草稿、日期、归档成功失败、并发输入、刷新、窄屏）及原创建/浮层测试。自动归档测试使用服务替身，真实飞书及安卓键盘/外部浏览器仍需实际账号真机验收。
