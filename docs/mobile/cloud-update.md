# 页面云更新（原生协议 1）

首次需覆盖安装 0.2.6（versionCode 17），旧的 0.2.5 无法凭网页发布获得原生更新器。以后每次生产部署由构建脚本自动生成完整页面 ZIP、SHA-256 和 no-store 版本清单。用户联网启动后后台检查并下载，完整包校验通过才暂存，下次 Activity 启动应用；后台恢复不强制重载正在填写的页面。账户页提供检查入口与下载状态。应用图标、权限或原生协议变化仍需要 APK。

固定生产 HTTPS 来源，拒绝跳转、不关闭系统证书校验；ZIP 名称和摘要绑定。压缩包上限 8MB、解压后 20MB、最多 200 文件，仅允许 mobile/shared-sync 的公开页面资源；拒绝路径逃逸、工具目录、未知扩展名及缺少启动文件的残包。更新目录位于 app files 下 web-updates；绝不删除 WebView 数据、账号存储或任务数据库。

WebView 始终使用原 appassets origin 与原路径，任务、会话、离线待上传队列沿用原存储。完整版本目录按校验和隔离，激活时原子状态切换；启动成功握手后确认，超时或下次启动发现未完成握手时回退上一版并拒绝相同失败包。新版原生壳升级时仅重置页面更新目录，继续保留业务数据。单实例 Activity 避免两个页面加载到不同更新目录，独立 20 秒启动看门狗避免等待 JS 回调时不能回退。

验证：独立纯 Java BundleStore 回退/中断/路径攻击/哈希/数据哨兵用例；生成的完整 ZIP 浏览器加载和升级重载保留账号、待上传写入和任务；原有认证/同步与移动交互回归；Android 编译/lint 与原签名验证。自动验证不等于真实手机安装验收；首次安装后联网启动一次、返回退出再启动，检查账户页状态。

生产发布须确认网页首页、账号 API 和更新清单/ZIP 同一部署均可访问。故障时回退网页部署或发布更高 release 的已知可用页面包；不要靠清除用户数据修复。
