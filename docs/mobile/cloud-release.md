# App 0.2.0 云账号测试版

来源：main 48908a0（已发布网页验证码注册），仅增加版本号和打包验收。不改任务数据模型。

覆盖安装保留 applicationId=app.lambert.tasks.trial、WebView本地来源和原签名；签名必须匹配原0.1.9证书 SHA256 828cc500f34c957427f42f14209f98d1069042cc0d68d6ee22f5ebdb3ee4653c，否则构建失败，不分发。

真实 Android 测试：生产公开配置可达、SDK账号模块渲染、验证码注册入口、登录前不激活云工作台、禁止网络后本地任务保留；原有键盘遮挡测试继续运行。不会发送真实邮件或操作真实账号。双设备真实账号与真实邮件验收仍需本人操作。

用户流程：先网页注册并登录；原电脑选择“检查并导入本机数据”，下载备份并核对后导入。App覆盖升级（不卸载、不清数据）；同邮箱登录；若手机有独有内容，同样先备份并检查导入；否则选择“使用云端工作台”。用测试任务核对手机新增→网页出现→网页完成→手机刷新显示完成，再测试离线补传和冲突处理。首次启用后后台同步保留未保存表单，并通过刷新提示接收远端更新。
