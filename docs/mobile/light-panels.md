# 轻量创建与账户界面

任务与项目共用紧凑底部输入框，日期、优先级、标签、项目采用细线 SVG 图标。单选菜单点击即选中关闭；多选由右上对勾结束。点浮层外只关闭当前浮层，保留创建草稿；返回键逐层关闭。

日期采用本地日历面板，支持今天、明天、下周一、切月、清除与时间选择。日期和时间先暂存，右上对勾后写入创建草稿，创建提交后才保存任务。未经修改的完整旧时间戳保留秒数与时区。没有新增提醒发送功能。

我的账户沿用共同邮箱认证与同步模块；使用小对勾标志、浅底圆角卡片和带图标操作行。登录、注册验证码、导入确认、备份和冲突处理行为不变。

验证：32 个数据/认证测试；原有 19 类浏览器同步流程；14 类紧凑创建流程；新增 9 类轻量弹层流程（含 320/390/430 宽、360 高、时间保存、返回取消、完整时间戳保留）。同步服务由测试替身提供，未使用真实用户账号；安卓键盘与硬件返回仍需真机验收。
