# Android 0.1.0 测试包

应用ID app.lambert.tasks.preview，Android 8及以上。独立测试签名，不是商店审核版本；禁用调试，禁止外部网页跳转、文件访问、混合内容及Web权限请求。无网络、通讯录、相机、麦克风、定位及存储权限；业务数据保存在应用私有WebView目录，不上传。

原生使用Android官方WebViewAssetLoader提供包内HTML/CSS/JS，保留同源存储安全模型。网页已通过目标进度、任务创建、项目关联、复盘保存、离线重开等检查，APK执行assembleDebug、lintDebug、apksigner验证和aapt权限检查。未经实体手机验证，不保证不存在缺陷。

安装：下载APK后允许当前浏览器/文件管理器安装此来源，安装完成可关闭该来源权限。保留系统安全检测；若显示明确恶意软件拦截，停止安装并反馈完整提示，不要求用户绕过。未知开发者提示不等于检测到恶意代码。

当前不连接云同步/飞书。手机APP、浏览器预览及电脑数据相互独立；先用少量测试任务。卸载或清除应用数据会删除本地记录。测试签名通过CI缓存维持，但不是正式长期密钥托管，后续正式版需要持久化保护签名密钥及设计数据导出迁移。
