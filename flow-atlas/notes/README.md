# Flow Atlas · 网络连接三层图 v0.3

独立模块分支 `feat/flow-atlas-network`，尚未合入 OS 工作台。入口 `/flow-atlas/`。

## 本版范围

- L1：11 个完整主流程节点，蛇形连线与去程/回程演示。
- L2：一次只展开一个主模块，48 个细步骤就地展开。
- L3：每个细步骤有自己的定义、目的、过程、输入输出、例子和易错点。
- 搜索定位、概念前后翻阅、深链接；移动端概念区排在地图后。
- 默认暂停。播放不会改变阅读选择；响应回程跳过 URL/HTTP 准备和 DNS 查询，结束后自动停止。动画是学习示意，不是抓包时序。

学习范围为 HTTP/1.1 + TCP 的新连接，包含 HTTPS 需要的 TLS 提示。HTTP/3、缓存/连接复用的完整分支、整本书章节、编辑后台不在本版范围内。服务器网络中的防火墙、负载均衡等是可能部署的组件，顺序不代表所有网站。

## 使用

打开 `flow-atlas/index.html`，或在仓库根目录运行 `python3 -m http.server 8000` 后访问 `/flow-atlas/`。无框架、无外部资源加载、无 AI 在线请求、无工作台数据读写。只在用户点击资料链接时离开本站。

- `data/network-data.js`：内容数据；概念 ID 需保持稳定。
- `atlas.js`：展开、搜索、概念展示和演示引擎。
- `atlas.css`：独立主题，不影响 OS 样式。
- `window.FlowAtlas.getState()`：只读运行状态，供测试/将来嵌入使用。
- `window.FlowAtlas.destroy()`：取消动画、观察器和事件监听。

沿用用户提供的 Flow Atlas v0.2 结构和冻结交互规则；本版概念为独立编写的教学摘要，未复制整书文本。参考资料在数据源中列出 MDN 与 TCP RFC；后续可逐章结合用户书籍校正。
